# IA-README - Guía para Agentes de IA

Este archivo contiene las instrucciones y el contexto necesario para que cualquier agente de IA pueda trabajar de forma efectiva en este proyecto.

## Estructura del Proyecto

- **CDJ-Front**: Aplicación Frontend desarrollada en Angular.
- **CDJ-Back**: Directorio destinado al Backend (tecnología pendiente de confirmación).

## Instrucciones para el Agente

### 1. Estilo y Diseño
- El proyecto utiliza **Tailwind CSS**.
- Priorizar diseños **premium, modernos y vivos**.
- Evitar colores genéricos; usar paletas armoniosas y modo oscuro si es posible.
- Implementar micro-animaciones y hover effects para mejorar la experiencia de usuario.

### 2. Flujo de Trabajo
- Mantener la separación de responsabilidades entre componentes y servicios.
- Seguir las mejores prácticas de Angular (Standalone components, Signals si aplica).
- Actualizar siempre este archivo o el `task.md` si hay cambios significativos en la arquitectura.

### 3. Stack Tecnológico
- **Frontend**: Angular 21+, Tailwind CSS.
- **Backend**: (Pendiente de definición).
- **Gestor de Paquetes**: Yarn (prioridad), npm (compatible).

## Contacto / Contexto Adicional
Este proyecto es una iniciativa de **Ciudadanía Digital**. El objetivo es crear una plataforma "super cool" y funcional.
